# Isotope eCommerce manual

Create your first shop, learn how to run it, and find help when you need it.

Isotope adds products, a shopping cart, checkout, and order management to your Contao website. This manual starts with the basics. You do not need previous experience running an online shop.

> [!TIP]
> For Isotope 2, see the [Isotope 2 manual](https://docs.isotopeecommerce.org/v2/en/).

## One shop throughout the manual

Our example shop is **Trail Supply**, a small clothing shop. You start with its **Trail T-shirt**, then add size and color choices, a printed name, and quantity prices as you learn.

The same products, prices, and names recur in later chapters. A hoodie illustrates related products and a basket with different items. Garment wash is used only where a product sold by volume makes comparison pricing easier to explain. Meet them in [Our example shop](concepts/example-shop.md).

## How the sections fit together

**Getting started** takes you from understanding the tools to placing your first test order. **Shop setup** explains the settings you choose before launch or change as the business grows. **Daily use** covers the work you repeat once the shop is running.

**Developers** is a separate technical reference for installation commands, templates, integrations, upgrades, and implementation notes. Shop owners can follow the user chapters without reading it.

This manual covers Isotope 3. Installed extensions can add features and settings. Before accepting real orders, work through [Before you open the shop](getting-started/launch.md).
