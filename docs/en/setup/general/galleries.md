# Product images and galleries

Product images belong to a product. A gallery configuration decides how those images are presented: sizes, link behavior, fallback image, and template.

Use a compact gallery for product lists and a larger gallery for product details. This lets customers browse quickly and then inspect the item before buying.

## Configure a gallery

1. Open **Configuration → Galleries** and create a record.
2. Choose the available gallery type and a descriptive name.
3. Set the main image and additional image sizes.
4. Choose the image action: no link, product reader, or image/lightbox link.
5. Optionally choose a placeholder for products without an image.
6. Select the gallery in the product type's list and reader settings.

A content element can override the product type's gallery. Check that override if changing the type appears to have no effect.

## Prepare useful images

Use consistent framing so list pages are easy to scan. Add alternate text that identifies the product or useful detail. Show multiple views when shape, scale, or included parts might otherwise be unclear.

A placeholder avoids a broken visual layout but does not replace a product photograph. Review products without images before launch.

## Test the presentation

Check the list on a phone and desktop, then open the reader. Verify that important parts are not cropped, the image action behaves as intended, and variant-specific images follow the selected variant.

For multiple languages, inspect the image translation settings as well as the product description. Some images contain text and need replacement, while others only need translated alternate text.

Isotope 3's upgrade notes remove ElevateZoom and watermark options. Do not expect those controls from older gallery tutorials.
