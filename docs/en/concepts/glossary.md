# Glossary

| Term | Meaning |
| --- | --- |
| Alias | A readable identifier used in a product URL |
| Attribute | A product field, such as material, color, or description |
| Backend | The administration area used by staff |
| Base price | A comparison price per reference quantity, such as per 100 g |
| Billing address | The address associated with the buyer and billing |
| Cart | The customer's provisional selection before ordering |
| Category | A Contao page to which products are assigned |
| Checkout | The process of collecting addresses and choices and placing the order |
| Content element | A block placed in a Contao article, such as an Isotope cart |
| Customer-defined option | Information the buyer supplies, such as engraving text |
| Document | A generated record associated with an order, such as an invoice |
| Frontend | The public website used by customers |
| Fulfillment | Preparing and delivering what the customer ordered |
| Gross | Including tax |
| GTIN | A standardized trade item identifier, distinct from your internal SKU |
| Guest | A customer shopping without a signed-in member account |
| Member | A Contao frontend account |
| Member group | A group used for customer access or business conditions |
| Net | Excluding tax |
| Notification | A configured message, for example an order confirmation |
| Order | The recorded purchase after checkout submission |
| Payment gateway | An integration with a payment provider |
| Price tier | A unit price that applies from a specified quantity |
| Product type | A reusable selection of product fields and behavior |
| Reader | The element displaying one product's details |
| Rule | A reusable set of conditions checked against the shopping context |
| Shipping address | The destination for the goods |
| SKU | Your stock keeping unit, an internal identifier for a sellable item |
| Store configuration | Settings for currency, addresses, prices, and checkout methods |
| Store ID | A grouping of site roots used for shared shop context such as carts and addresses |
| Tax class | The included and applicable tax treatment assigned to a price |
| Tax rate | A tax percentage, optionally restricted by a rule |
| Token | A placeholder replaced with a value in supported text contexts |
| Transaction | A payment attempt or associated payment record |
| User | A Contao backend staff account |
| Variant | A specific version of a product, such as a size and color combination |
| Workflow | The allowed transitions from one status to another |

Start with [How a shop works](shop.md) to see these terms together.
