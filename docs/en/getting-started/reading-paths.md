# Find your next task

Each section has its own reading order. Choose the section that matches your situation, then follow its overview and sidebar.

## Build a new shop

[Start here](index.md) → [Contao essentials](../concepts/contao.md) → [How a shop works](../concepts/shop.md) → [Our example shop](../concepts/example-shop.md) → [Installation](installation.md) → [Your first shop](first-shop.md).

After the first purchase works, use [Shop setup](../setup/index.md) for the configuration your business needs. Finish the [launch checklist](launch.md) before accepting customers.

## Configure the shop

The [setup roadmap](../setup/index.md) follows the dependencies: store → taxes → catalog → storefront → checkout → daily operations. Optional features come afterwards.

Start from the relevant stage when changing an existing shop. For example, prepare tax rules and rates before assigning a tax class, or prepare order statuses before configuring payment methods.

## Run an existing shop

The [Daily use overview](../usage/index.md) groups recurring tasks:

- Handle purchases with [Processing orders](../usage/orders.md), then [Returns and refunds](../usage/returns.md) when needed.
- Maintain the catalog with [Products](../usage/products.md), [Variants](../usage/variants.md), [Prices](../usage/prices.md), [Pricing recipes](../usage/pricing-recipes.md), and [Recommendations](../usage/related-products.md).
- Keep the shop running with [Routine checks](../usage/maintenance.md) and [Troubleshooting](../usage/troubleshooting.md).

## Maintain or extend the software

Use the separate [Developer guide](../developers/index.md). Check the target version first, install or upgrade the application, configure it, then customize and verify the affected behavior.

Use a test installation with fictional customer details for exercises. The Trail T-shirt remains the example throughout these routes.
