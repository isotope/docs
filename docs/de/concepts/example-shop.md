# Unser Beispielshop: Trail Supply

Trail Supply verkauft Bekleidung. Im ganzen Handbuch arbeitest du mit demselben kleinen Katalog, damit du dich auf das Erlernen von Isotope konzentrieren kannst.

Du musst diese Produkte nicht selbst verkaufen. Verwende die Beispiele auf einer Testwebsite und übertrage die Ideen danach auf deinen eigenen Katalog.

## Mit dem Trail-T-Shirt beginnen

| Einstellung | Beispielwert |
| --- | --- |
| Shopname | Trail Supply |
| Shopkonfiguration | Trail Supply Inland |
| Produkt | Trail-T-Shirt |
| Kategorieseite | T-Shirts |
| Produkttyp für die erste Übung | Bekleidung |
| Erster verkaufbarer Artikel | Blau, Größe M |
| Artikelnummer | `TSHIRT-BLUE-M` |
| Währung | EUR |
| Eingegebener Preis | 22,00, einschließlich der fiktiven Beispielsteuer von 10 % |
| Preisanzeige | Brutto |
| Steuerklasse | Standardwaren |
| Versandart | Standardlieferung |
| Versandkosten | 5,50, einschließlich derselben Beispielsteuer |
| Zahlungsart zum Lernen | Testzahlung mit dem Typ Barzahlung |

Eine **Artikelnummer (SKU)** ist deine interne Artikelkennung. Ein **Bruttopreis** enthält Steuer. Das [Steuerkapitel](prices-and-taxes.md) erklärt die Berechnung vor der Einrichtung.

**Alle Steuerprozentsätze hier sind fiktive Lernwerte.** Die Währung sagt nichts über die Steuerpolitik eines Landes aus. Verwende für deinen echten Shop die zu deinem Geschäft passende Behandlung und die richtigen Sätze.

Wähle ein Land als inländisches Testziel. Verwende dieses Land einheitlich für Standardwerte und erlaubte Adressen. Die internationale Steuerübung nennt es A und führt ein zweites Zielland B ein.

## Dasselbe Produkt schrittweise erweitern

In [Dein erster Shop](../getting-started/first-shop.md) hat das Trail-T-Shirt eine feste Größe und Farbe. Du nennst diese in der Beschreibung und verkaufst es als einfaches Produkt. Es gibt noch keine Größen- oder Farbauswahl.

Im Kapitel [Varianten](../usage/variants.md) bietest du Blau und Schwarz in S, M und L an. Jede verkaufbare Kombination erhält eine eigene Artikelnummer, etwa `TSHIRT-BLACK-L`. Der normale Preis bleibt für alle Kombinationen 22,00.

Mit einem kundendefinierten Feld **Aufgedruckter Name** können Käufer später „Sam“ auf dem T-Shirt anfordern. Es zeigt die Erfassung von Text, in unserem Beispiel ohne Aufpreis.

Die Mengenpreisübung verwendet diese Preise für dasselbe T-Shirt:

| Menge ab | Bruttostückpreis |
| --- | ---: |
| 1 | 22,00 |
| 5 | 19,80 |
| 10 | 17,60 |

Eine separate Übung für Geschäftskunden verwendet 17,60 ab Menge 1. Jede Übung erklärt, wann du diese Preise aktivierst. Sie sind in der Anleitung zum ersten Shop noch nicht aktiv.

## Zwei ergänzende Produkte

| Produkt | Dient zur Erklärung von |
| --- | --- |
| Trail-Hoodie | Ähnlichen Produkten und einem Warenkorb mit verschiedenen Produktpositionen |
| Textilwaschmittel, 250 ml zu 6,60 oder 500 ml zu 11,00 | Grundpreisen pro 100 ml |

Der Hoodie gehört auf die Kategorieseite Hoodies. Textilwaschmittel gehört auf Kleidungspflege. Diese Ergänzungen sind optional und folgen erst, wenn die T-Shirt-Bestellung funktioniert.

## Erwarteter Gesamtbetrag der ersten Bestellung

| Bestandteil | Netto | Beispielsteuer | Brutto |
| --- | ---: | ---: | ---: |
| Ein Trail-T-Shirt | 20,00 | 2,00 | 22,00 |
| Standardlieferung | 5,00 | 0,50 | 5,50 |
| Gesamt | 25,00 | 2,50 | 27,50 |

Spätere Steuerbeispiele ändern jeweils eine Bedingung und erklären das neue Ergebnis. Ein anderer anwendbarer Satz kann etwa den Bruttopreis ändern, während der Nettobetrag des T-Shirts 20,00 bleibt.
