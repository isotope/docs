# Glossar

| Begriff | Bedeutung |
| --- | --- |
| Alias | Eine lesbare Kennung in einer Produkt-URL |
| Attribut | Ein Produktfeld, etwa Material, Farbe oder Beschreibung |
| Backend | Der Verwaltungsbereich für Mitarbeiter |
| Grundpreis | Ein Vergleichspreis pro Bezugsmenge, etwa pro 100 g |
| Rechnungsadresse | Die dem Käufer und der Rechnung zugeordnete Adresse |
| Warenkorb | Die vorläufige Auswahl des Kunden vor der Bestellung |
| Kategorie | Eine Contao-Seite, der Produkte zugewiesen sind |
| Kasse (Checkout) | Der Ablauf zur Erfassung von Adressen und Auswahlmöglichkeiten sowie zum Absenden der Bestellung |
| Inhaltselement | Ein Block in einem Contao-Artikel, etwa ein Isotope-Warenkorb |
| Kundendefinierte Option | Eine Angabe des Käufers, etwa ein aufgedruckter Name |
| Dokument | Ein erzeugtes, einer Bestellung zugeordnetes Schriftstück, etwa eine Rechnung |
| Frontend | Die öffentliche Website für Kunden |
| Auftragsabwicklung (Fulfillment) | Vorbereitung und Lieferung der bestellten Waren |
| Brutto | Einschließlich Steuer |
| GTIN | Eine standardisierte Handelsartikelnummer, unabhängig von deiner internen Artikelnummer |
| Gast | Ein Kunde ohne angemeldetes Mitgliedskonto |
| Mitglied | Ein Contao-Frontend-Konto |
| Mitgliedergruppe | Eine Gruppe für Kundenzugriff oder Geschäftsbedingungen |
| Netto | Ohne Steuer |
| Benachrichtigung | Eine konfigurierte Nachricht, etwa eine Bestellbestätigung |
| Bestellung | Der erfasste Kauf nach dem Absenden an der Kasse |
| Zahlungsschnittstelle (Payment Gateway) | Eine Anbindung an einen Zahlungsanbieter |
| Preisstaffel | Ein Stückpreis, der ab einer bestimmten Menge gilt |
| Produkttyp | Eine wiederverwendbare Auswahl von Produktfeldern und Verhalten |
| Leser (Reader) | Das Element zur Anzeige der Details eines Produkts |
| Regel | Eine wiederverwendbare Gruppe von Bedingungen, die gegen den Einkaufskontext geprüft werden |
| Lieferadresse | Das Ziel für die Waren |
| Artikelnummer (SKU) | deine interne Kennung für einen verkaufbaren Artikel |
| Shopkonfiguration | Einstellungen für Währung, Adressen, Preise und Bestellmethoden |
| Shop-ID | Eine Gruppierung von Startpunkten für gemeinsamen Shopkontext wie Warenkörbe und Adressen |
| Steuerklasse | Die einem Preis zugewiesene enthaltene und anwendbare steuerliche Behandlung |
| Steuersatz | Ein Steuerprozentsatz, optional durch eine Regel eingeschränkt |
| Token | Ein Platzhalter, der in unterstützten Textkontexten durch einen Wert ersetzt wird |
| Transaktion | Ein Zahlungsversuch oder ein zugehöriger Zahlungsdatensatz |
| Benutzer | Ein Contao-Backend-Konto für Mitarbeiter |
| Variante | Eine bestimmte Ausführung eines Produkts, etwa eine Größen- und Farbkombination |
| Workflow | Die erlaubten Übergänge von einem Status zum nächsten |

Beginne mit [So funktioniert ein Shop](shop.md), um diese Begriffe im Zusammenhang zu sehen.
