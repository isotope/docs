# Ähnliche Produkte einrichten

Ähnliche Produkte sind von dir ausgewählte Empfehlungen, etwa der Trail-Hoodie neben dem Trail-T-Shirt. Sie helfen Kunden, ein passendes Ergänzungsprodukt zu entdecken. Sie fügen kein Paket automatisch zum Warenkorb hinzu.

Eine **Beziehungskategorie** bündelt die Art der Empfehlung. Sie ist von den Contao-Seitenkategorien der Produktlisten getrennt.

## Empfehlungsgruppen konfigurieren

1. Öffne **Konfiguration → Beziehungskategorien**.
2. Erstelle „Passt dazu“ für T-Shirt und Hoodie.
3. Erstelle optional „Kleidungspflege“ für Textilwaschmittel.
4. Platziere ein Inhaltselement für ähnliche Produkte auf der Produktdetailseite.
5. Wähle die Beziehungskategorien, die das Element anzeigen soll.
6. Weise eine Testempfehlung zu und prüfe sie auf der Produktseite.

Die Produktredaktion kann jetzt [Empfehlungen pflegen](../../usage/related-products.md), ohne die Seite zu ändern oder eine weitere Gruppe zu definieren.
